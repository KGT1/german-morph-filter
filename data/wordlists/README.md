# Passphrase wordlists

Curated German words for the sentence passphrases generated by
[ger-morph-pw-gen](https://github.com/KGT1/ger-morph-pw-gen):

    flinkerFuchs.malt.leise.roteTomate.42!

## Files

| path | what |
|---|---|
| `curated/nouns.tsv`, `curated/adjectives.tsv`, `curated/verbs.tsv` | **Source of truth.** Every candidate with its forms, frequency, usage flags and review decisions (`keep`, `kid`, `gender_ok`, `concrete`, `animate`, `forms_ok`, `adverb_ok`, `takes_acc_obj`, `note`). Edit decisions here. |
| `blocklist.txt` | Words that are never emitted, whatever the review says. |
| `REVIEW_GUIDE.md` | The rules the review followed. Use it when re-reviewing or adding words. |
| `CANDIDATES.md` | How the candidates were produced (sources, filters, counts per stage). |
| `../output/wordlist_main.json`, `../output/wordlist_kids.json` | Built lists, produced by `python src/build_wordlists.py`. |

## Selection rules (applied by `src/build_wordlists.py`)

- **Keyboard-layout safety:** every form uses only `a–x`/`A–X`, so it types the same on German QWERTZ and US QWERTY. There is no y/z, umlaut or ß.
- **Nouns:** `keep` and `gender_ok`, and `concrete` or `animate`. Picturable words are easier to remember.
- **Adjectives:** `keep` and `forms_ok`. Any adjective sharing a surface form with an earlier one is dropped, so no password is more likely than another.
- **Verbs:** `keep` and `takes_acc_obj` ("Der Fuchs malt den Ball").
- **Adverbs:** base forms of selected adjectives with `adverb_ok`.
- **Kids list:** all of the above, plus `kid`.
- **Blocklist:** a word is dropped if it is in `blocklist.txt`, or if every Wiktionary sense is tagged vulgar/offensive/slur.
